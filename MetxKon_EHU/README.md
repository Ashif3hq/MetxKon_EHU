# MetxKon Lab

**MetxKon Lab** is a web-based workspace for mechanical compression testing and materials analysis, developed as a separate research-oriented project.

## Project goals
- Import and organize compression-test datasets.
- Visualize force, displacement, stress and strain data.
- Support transparent, reproducible calculations.
- Compare specimens and test conditions.
- Export plots, processed data and analysis summaries.

> Calculation methods, assumptions and validation datasets will be documented before analytical features are considered reliable.

## Current status
Early foundation stage. The application scope and scientific workflow are being defined.

## Run locally
1. Clone this repository.
2. Open `index.html` in a browser.

No build system or dependencies are required at this stage.

## Structure
- `index.html` — application shell
- `assets/css/styles.css` — styling
- `assets/js/app.js` — app entry point
- `docs/` — methodology, architecture and roadmap

## Scientific validation
Results are not intended for research conclusions until calculation methods have been specified and verified against known or independently calculated reference cases.
