# Architecture

Initial static-web architecture; evolve only when project requirements justify it.

- **UI:** HTML and CSS
- **Application logic:** vanilla JavaScript modules
- **Data input:** file-based import, initially CSV
- **Analysis:** isolated calculation functions, independent of UI
- **Visualization:** select charting approach after requirements are established
- **Testing:** automated tests for calculation logic, planned

Keep raw data, transformed data, calculations, visualization and export concerns separate.
