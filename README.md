# MetxKon Lab

Browser-based mechanical test data analyzer for tensile and compression testing. This prototype supports delimited text import, stress–strain and force–displacement plotting, selectable-region linear regression, peak analysis, and CSV/PNG export.

## Run
Open index.html in a modern browser; no build step required.

## Data
CSV, TXT, DAT, TSV and other delimited text exports. Export machine data to CSV/TXT first if using proprietary or Excel formats. Data is processed locally.

## Important
Prototype: validate column mapping, units, specimen geometry, strain definitions, regression region and outputs against test standards. The final data point is not verified fracture automatically.
