Browser-based mechanical test data analyzer for tensile and compression testing. This prototype supports delimited text import, stress–strain and force–displacement plotting, selectable-region linear regression, peak analysis, and CSV/PNG export.

## Run
Open [the web app](https://ashif3hq.github.io/MetxKon_EHU/) or open `MetxKon_EHU/index.html` locally in a modern browser. No build step required.

## Data
CSV, TXT, DAT, TSV and other delimited text exports. Export machine data to CSV/TXT first if using proprietary or Excel formats. Data is processed locally in your browser.

## Important
Prototype: validate column mapping, units, specimen geometry, strain definitions, regression region and outputs against test standards. Peak stress is displayed by magnitude; sign conventions are not automatically corrected. The final data point is not verified fracture automatically.
